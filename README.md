# FRIDAY studio

Hjemmeside for FRIDAY studio: hjemmesider, ordresystemer, skræddersyede systemer og grafisk design til små virksomheder.

Sider: `index.html` (forside), `ydelser.html` (ydelser og priser), `ordresystem.html` (demo af ordresystem), `proces.html`, `om-os.html`, `spoergsmaal.html` og `book-et-moede.html`. `priser.html` sender videre til `ydelser.html`. Fælles styling ligger i `styles.css` og fælles JavaScript i `main.js`. Siden kan hostes direkte med GitHub Pages.

Ting der skal opdateres senere:
- Priserne i sektionen "Priser" er pladsholdere.
- Bookingformularen sender endnu ikke data nogen steder hen. Den udsender et `friday:booking`-event med formularens data, klar til at blive koblet på det interne system.
- CVR, adresse, telefon og e-mail i footeren.
- Cases og kundeudtalelser.
